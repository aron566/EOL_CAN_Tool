# EOL CAN Tool 使用说明书

## 1. 工具简介

EOL_CAN_Tool 是一款基于 Qt 的 CAN 总线 EOL(End-Of-Line,产线终检)测试上位机软件,用于雷达等产品的量产测试与调试。支持多品牌 CAN 设备、报文收发与解析、数据回灌、EOL 调试、固件升级等功能。

支持的 CAN 设备品牌:

- 周立功(ZLG)全系
- 广成(GCAN)CAN / CAN-FD
- 同星(TOSUN)
- Kvaser 全系

## 2. 安装与启动

### 2.1 使用安装包

运行 `EOL_CAN_Tool_Setup_vX.Y.Z.exe`,按向导完成安装。默认安装到 `%LOCALAPPDATA%\EOL_CAN_Tool`,开始菜单与桌面会创建快捷方式,无需管理员权限。

### 2.2 升级

软件启动时会自动检查更新(见第 10 节)。也可直接运行新版本安装包覆盖安装,升级会保留原有配置文件。

## 3. CAN 设备连接

### 3.1 选择设备

CAN 设备连接电脑后,依次选择「品牌」→「设备型号」→「通道」(通道编号从 0 开始,可选择打开单个通道或全部打开)。

- **设备索引**:用于区分多个同型号 CAN 设备。
- **设备信息**:读取设备 SN、通道数等信息,可读时点击将弹窗显示。

### 3.2 设置通讯参数

按被测设备要求设置波特率等通讯参数。

### 3.3 启动连接

依次点击:打开 → 初始化 → 启动。点击「更多」进入 CAN 通讯测试主页面,上方窗口显示设备是否打开/启动成功。

## 4. CAN 通讯测试

本页支持:

- 两个以上通道数据的收发
- 掩码配置
- 接收数据转字符串输出(可指定转换的 CAN 通道与 CAN ID)
- 手动发送报文
- 报文收发双色显示,带时间戳
- 提供进入其他菜单的按钮
- 手动发送窗口可在数据尾部自动追加常用 CRC 值(点击对应 CRC 按钮自动计算并追加)
- 定时发送 / 定次发送(定时发送帧数不填则无限发送,周期最小 1 ms)
- 曲线图表功能(勾选可将数据转发至图表曲线显示)

### 4.1 数据回灌

数据回灌需要设置回灌的数据格式,通常为 txt 或 csv 文件。设置时可指定:

- CAN ID 所在索引
- 数据开始的索引
- 帧间间隔(每发送完一帧后的等待时间,ms)
- 特殊等待 CAN ID(指定 CAN ID 发送完成后的等待时间,可不设置)
- 特殊等待数据(遇到此数据等待特定时间,可不设置)
- 特殊等待数据索引(默认 0,可不设置)

## 5. EOL 调试

EOL 调试页面功能:

- 进入 / 退出 EOL 模式、重启设备
- 各种类型表的写入与读取,含进度显示
- 报文传输返回值显示
- 进入下级页面(信息读写、天线校准、RCS 校准)

### 5.1 信息读写

- 版本、SN、mounID 读写测试
- DTC 检测
- VCAN 测试

### 5.2 天线校准(获取 2D 数据)

- 设置目标模拟器 RTS 相关参数
- 设置转台水平转动相关参数
- 设置转台上下抬头相关参数
- 模拟发送转台信息给雷达,请求 2DFFT 数据
- 生成 2DFFT 数据 CSV

> 「添加配置」为增量式添加,重新配置需先清除配置;仅需某方向 2D 数据时,将其他方向条件置空即可。

### 5.3 RCS 标定看目标

- 设定阈值
- 持续获取目标数据
- 通过「刷新显示过滤」筛选指定条件的目标
- 统计目标设置,进一步过滤目标输出到统计列表

> 前提:先添加一个条件到阈值列表方可启动看目标。

## 6. SHELL 调试

- 控制台字体颜色切换
- 复制粘贴(复制后使用鼠标右键粘贴)
- `TAB` 键补全命令
- 上下键查看历史命令
- 回车键执行命令

## 7. 网络调试

网络调试提供两个网络设备:RTS、PLC。

### 7.1 RTS 网络

RTS 使用 UDP 通讯,发送与接收端口区分,PC 端需启用两个端口(一个监听接收、一个发送控制)。

- 客户端端口(发送端口)、服务器端口(接收端口)
- 通讯 IP 设为本机局域网 IP(与 RTS 同一子网)
- 工作方式设为「客户端」
- 点击「启动」,成功后可在「更多 → EOL 调试页面」看到 RTS 控制按钮

### 7.2 PLC 网络

PLC 使用 Modbus TCP,即将支持。

## 8. 固件升级

1. 点击「固件选择」,选择 bin 文件
2. 点击「启动升级」,复位雷达(可进入 EOL 模式点击「重启设备」进行软复位)
3. 升级成功后界面有提示

> 升级过程中关闭页面,工具将退出升级流程。

## 9. 曲线图表

曲线图表要求输入格式:`$1 2 3;`

- 以 `$` 开头
- 以 `;` 结尾
- 中间数字以空格隔开
- 每个数字代表对应通道在当前时刻的数值(1 = 通道 0,2 = 通道 1,3 = 通道 2)

数据通道选择:

- **vcom**:虚拟通道,数据来自非串口设备(可勾选曲线图表进行数据流转发)
- **非 vcom**:数据使用串口

## 10. 软件更新

有新版本发布时,软件每次启动会提醒更新。更新会下载新版本安装包并提示安装。

## 11. 常见问题

- **设备打不开**:检查设备驱动是否安装、是否被其他程序占用。
- **收不到报文**:确认通讯参数与波特率设置正确,并已依次执行「打开 → 初始化 → 启动」。
- **升级失败**:确认网络正常、安装包完整,或改用新版本安装包覆盖安装。
